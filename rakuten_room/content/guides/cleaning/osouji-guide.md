# 大掃除の始め方｜順番・場所別の道具と、年末に慌てないコツ
年末の大掃除は、順番と道具を決めておくだけでぐっとラクになります。場所ごとに必要な道具と、効率よく進めるコツをまとめました。

> 掃除は「上から下へ」「奥から手前へ」が基本。ほこりは上から落ちるので、照明や棚の上→窓→床の順に進めると二度手間になりません。年末にまとめてやるより、11月から場所ごとに分けて少しずつ進めると、寒さや混雑も避けられます。

## 進める順番
1. **照明・エアコン・棚の上**：ほこりを落とす
2. **窓・網戸・サッシ**：晴れて乾きやすい日に
3. **キッチン**：換気扇やコンロまわりは時間がかかるので早めに
4. **浴室・洗面・トイレ**
5. **床**：最後にまとめて

## 場所別のおもな道具
| 場所 | あると便利な道具 |
|---|---|
| 高いところ | ハンディモップ、伸縮できるワイパー |
| 窓・サッシ | スクイージー、すき間用ブラシ、マイクロファイバークロス |
| キッチン | スポンジ、使い捨ての手袋、キッチンペーパー |
| 浴室 | 柄つきブラシ、メラミンスポンジ |
| 床 | フローリングワイパーとシート |

## 気をつけたいこと
- 洗剤は製品の表示どおりに使う。塩素系と酸性タイプは混ぜない
- メラミンスポンジは研磨するので、コーティングされた面や光沢のある素材には使わない
- 高いところの作業は、安定した踏み台を使う

## まとめ買いのポイント
シートやスポンジは大掃除でたくさん使います。**1枚・1個あたりの価格**で比べて、年内に使い切れる量を選びましょう。床掃除のシートは[フローリングワイパーシートの選び方](/cleaning/wiper-sheet-guide/)も参考にしてください。
