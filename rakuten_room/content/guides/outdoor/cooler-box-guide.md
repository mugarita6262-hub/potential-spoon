# クーラーボックスの選び方｜ハードとソフトの違い、容量と保冷力の目安
クーラーボックスは、キャンプやバーベキュー、釣り、まとめ買いの持ち帰りにも使える道具です。種類の違いと、人数や日数に合った容量、保冷力の見方をまとめました。

> 長時間しっかり冷やしたいなら断熱材の厚いハードタイプ、日帰りや持ち運びのしやすさを重視するなら軽くたためるソフトタイプが目安です。容量は、日帰りで2〜3人なら20〜30L前後、1泊以上なら40L以上がひとつの目安。保冷剤と組み合わせて使うのが基本です。

## ハードとソフトの違い
| 種類 | 特徴 | 向いている使い方 |
|---|---|---|
| ハードタイプ | 保冷力が高く、丈夫。重くかさばる | キャンプ・1泊以上・釣り |
| ソフトタイプ | 軽く、使わないときはたためる | 日帰り・買い物・サブ用 |

## 容量の目安
| 人数・日数 | 容量の目安 |
|---|---|
| 1〜2人・日帰り | 10〜20L前後 |
| 2〜3人・日帰り | 20〜30L前後 |
| 家族・1泊以上 | 40L以上 |

2Lのペットボトルを立てて入れたいなら、内側の高さも確認しましょう。

## 保冷力の見方
- **断熱材**：発泡スチロール、ウレタン、真空パネルなど。一般的に真空パネルは保冷力が高く、価格も高め
- **保冷時間の表示**：「氷が〇日残る」など、メーカーごとの試験条件で表示されていることがある
- **ふたの密閉性**：ふたがしっかり閉まるほど冷気が逃げにくい

## 冷やすコツ
- 保冷剤は、冷気が下に流れるので食材の上にも置く
- 使う前にクーラーボックス自体を冷やしておく
- 直射日光を避け、日陰に置く
- ふたの開け閉めを少なくする
