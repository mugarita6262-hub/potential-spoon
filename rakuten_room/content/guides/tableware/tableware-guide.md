# 食器の選び方｜素材の違いと、電子レンジ・食洗機に対応しているかの確認
毎日使う食器は、見た目だけでなく使い勝手で選ぶと長く使えます。素材ごとの特徴と、買う前に確認したい表示をまとめました。

> 毎日使う食器は、電子レンジと食洗機に対応しているものを選ぶとラクです。商品ページの「電子レンジ可」「食洗機可」の表示を確認しましょう。金や銀の線（上絵）が入った食器は、電子レンジで使えないことが多いので注意が必要です。

## 素材ごとの特徴
| 素材 | 特徴 | 気をつけたいこと |
|---|---|---|
| 磁器 | 薄くて硬く、丈夫。白くつるっとしている | 落とすと割れる |
| 陶器 | 厚みがあり、ぬくもりのある風合い | 吸水しやすく、においや色が移ることがある |
| 強化磁器 | 割れにくく加工された磁器 | 普通の磁器より少し重め |
| ガラス | 涼しげで料理が映える | 耐熱ガラス以外は急な温度変化に弱い |
| 木・漆 | 軽くて熱が伝わりにくい | 電子レンジ・食洗機は使えないものが多い |

## 確認したい表示
- **電子レンジ可**：温め直しに使うなら必須
- **食洗機可**：食洗機を使う家庭は必ず確認
- **オーブン可**：グラタンなどに使うなら

## そろえ方のコツ
同じシリーズでサイズ違いをそろえると、重ねて収納しやすく、食卓にも統一感が出ます。よく使うのは取り皿（直径15〜18cm前後）と、主菜用の大きめのお皿です。
