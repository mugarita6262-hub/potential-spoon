# お菓子のまとめ買いガイド｜詰め合わせ・訳ありの選び方と賞味期限
お菓子は、詰め合わせや「訳あり」のまとめ買いで、1個あたりの価格を下げやすい商品です。上手にまとめ買いするためのポイントをまとめました。

> まとめ買いは「1個（1袋）あたり」の価格と、届いてから食べ切るまでの賞味期限で判断しましょう。「訳あり」は形の不ぞろいや外装の傷などが理由のことが多いので、何が訳ありなのかを商品ページで確認してから選ぶと安心です。

## まとめ買いの種類
| 種類 | 特徴 |
|---|---|
| 同じ商品のケース | 1個あたりが安くなりやすい。好きな定番がある人向け |
| 詰め合わせ・アソート | いろいろな味を楽しめる。来客や子どものおやつに |
| 訳あり | 割れ・形の不ぞろい・外装の傷など。味は通常品と同じものが多い |
| 個包装の大袋 | 小分けで配りやすく、湿気にくい |

## 1個あたりの価格で比べる
「価格（送料込み）÷ 個数（袋数）」で1個あたりを出します。内容量（g）が違う商品同士なら、100gあたりにそろえると比べやすくなります。

## 「訳あり」で確認したいこと
- **何が訳ありか**：割れ・欠け、形の不ぞろい、外装の印字ミス、賞味期限が近い など
- **賞味期限**：期限が近いことが理由の場合は、食べ切れる量か確認
- **個包装かどうか**：訳ありは簡易包装のこともある。湿気やすいお菓子は保存方法も考える

## 保管と食べ切り
- 直射日光・高温多湿を避ける。チョコレートは夏場の温度に注意
- 開封したら早めに食べ切る。保存袋やクリップで湿気を防ぐ
- アレルギーがある場合は、原材料表示を必ず確認する
