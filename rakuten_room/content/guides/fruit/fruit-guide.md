# 果物のお取り寄せガイド｜旬の時期、「訳あり」の選び方と届いてからの保存
果物は旬の時期に産地から取り寄せると、手頃な価格でたっぷり楽しめます。主な果物の旬と、「訳あり」の選び方、届いてからの保存のコツをまとめました。

> 自宅用なら、見た目やサイズが不ぞろいな「訳あり」がお得です。届いたら箱から出して傷んだものを取り分け、果物ごとに合った方法で保存しましょう。量が多い箱買いは、食べ切れるペースを考えて選ぶのがコツです。

## 主な果物の旬（目安）
| 果物 | 主な時期 |
|---|---|
| みかん | 11月〜2月ごろ |
| りんご | 10月〜2月ごろ（品種によって違う） |
| 柿 | 10月〜11月ごろ |
| シャインマスカット | 8月〜10月ごろ |
| いちご | 12月〜5月ごろ |

産地や品種、その年の天候によって時期は前後します。

## 「訳あり」の選び方
- **何が訳ありか**：皮の傷や色むら、大きさの不ぞろいなど。味には関係ないことが多い
- **サイズの混在**：大小が混ざっていることがある。料理やジュースにも使えるなら気にならない
- **量**：訳ありは量が多めのことも。食べ切れるか考えて選ぶ

## 届いてからの保存
| 果物 | 保存のコツ |
|---|---|
| みかん | 箱から出して、風通しのよい涼しい場所に。重ねすぎない |
| りんご | ポリ袋に入れて冷蔵庫の野菜室へ。他の果物と分けて保存 |
| 柿 | ヘタを下にして、乾燥しないようにして冷蔵庫へ |
| ぶどう | 洗わずに袋に入れて冷蔵庫へ。食べる直前に洗う |

箱の中で1つ傷むと周りにも広がりやすいので、届いたらすぐに中を確認しましょう。
