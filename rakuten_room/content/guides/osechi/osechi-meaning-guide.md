# おせち料理の意味｜黒豆・数の子・海老など、品ごとに込められた願い
おせち料理の一品一品には、新しい年への願いが込められています。代表的な料理の意味と、重箱の詰め方の基本をまとめました。おせちを選ぶときや、食卓での話題にどうぞ。

> 黒豆は「まめに働けるように」、数の子は「子孫繁栄」、海老は「腰が曲がるまで長生きできるように」など、それぞれに縁起のよい意味があります。全部そろえなくても、好きなものや意味を知って選ぶと、お正月がより楽しくなります。

## 代表的な料理と意味
| 料理 | 込められた願い |
|---|---|
| 黒豆 | まめに（健康に）働き、暮らせるように |
| 数の子 | 卵の数が多いことから、子孫繁栄 |
| 田作り | かつて田の肥料にしたことから、五穀豊穣 |
| 海老 | 腰が曲がるまで長生きできるように |
| 昆布巻き | 「よろこぶ」にかけて、喜びが多い一年に |
| 栗きんとん | 黄金色にちなみ、金運・豊かさ |
| 伊達巻 | 巻物に似ていることから、学問や文化の発展 |
| 紅白かまぼこ | 日の出に見立てた形と、紅白のめでたさ |

意味や由来には地域や家庭によって違いがあります。

## 重箱の基本
おせちは「めでたさを重ねる」という意味で、重箱に詰めるのが一般的です。段ごとに、祝い肴、焼き物、煮物などを分けて詰める形が多く見られます。最近は一段重や、洋風・中華風の料理が入ったおせちも人気です。

## おせちを選ぶときに
- 家族の好きな料理が入っているか、品目の一覧で確認する
- 人数に合った量か（〇人前の表示）
- 冷凍か冷蔵か、届く日と解凍の時間
