# ボールペンとノートの選び方｜インクの種類・ボールの太さ・罫線の違い
毎日使うボールペンやノートは、自分に合ったものを選ぶと書きやすさが大きく変わります。インクの種類やノートの罫線の違いなど、選ぶときのポイントをまとめました。

> なめらかに書きたいなら低粘度油性インクやゲルインク、にじみにくさや速乾性を重視するなら油性インクが目安です。細かい字を書くなら0.5mm前後、しっかりした線なら0.7mm前後。気に入ったペンは替芯をまとめ買いしておくと、本体を長く使えます。

## インクの種類
| 種類 | 特徴 |
|---|---|
| 油性 | にじみにくく、水に強い。書き味はやや重め |
| 低粘度油性 | 油性の強さと、なめらかな書き味を両立 |
| ゲルインク | 発色がよく、なめらか。乾くまで少し時間がかかるものも |
| 水性 | さらさら書ける。にじみやすい |

## ボールの太さ
- **0.3〜0.4mm**：手帳など細かい字に
- **0.5mm前後**：ノートや書類に。迷ったらこのあたり
- **0.7mm以上**：太くはっきりした線。宛名書きにも

## 替芯を使う
同じペンを使い続けるなら、替芯を買えば本体を買い直さずに済みます。替芯は品番がペンごとに決まっているので、本体に合う品番を確認してから買いましょう。

## ノートの罫線
| 罫線 | 行の幅 | 向いている使い方 |
|---|---|---|
| A罫 | 7mm | 大きめの字。ゆったり書きたい |
| B罫 | 6mm | いちばん一般的。授業や仕事のメモに |
| C罫 | 5mm | 小さい字でたくさん書きたい |
| 方眼 | ー | 図や表を書くことが多い |
