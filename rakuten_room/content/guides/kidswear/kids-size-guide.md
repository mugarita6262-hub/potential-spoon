# 子供服のサイズの選び方｜身長との関係と、通販で失敗しないコツ
すぐに大きくなる子どもの服は、サイズ選びがいちばんの悩みどころ。サイズ表示の見方と、通販で買うときのポイントをまとめました。

> 子供服のサイズは、多くが身長（cm）を基準に「80・90・100…」のように10cm刻みで表示されています。今の身長に合うサイズか、すぐ大きくなりそうならひとつ上のサイズを選ぶのが一般的です。ただし大きすぎると袖や裾がじゃまになるので、トップスは袖をまくれるか、パンツは裾を折れるかも考えて選びましょう。

## サイズ表示の目安
| 表示 | 身長の目安 |
|---|---|
| 80 | 75〜85cm |
| 90 | 85〜95cm |
| 100 | 95〜105cm |
| 110 | 105〜115cm |
| 120 | 115〜125cm |

ブランドによって作りが違うので、商品ページの実寸（身幅・着丈・股下）も確認しましょう。

## 通販で失敗しないコツ
- **今ぴったりの服の実寸を測る**：身幅や着丈を、商品ページの実寸と比べる
- **レビューのサイズ感**：「小さめ」「ゆったり」などの声を参考に
- **セット・まとめ買い**：毎日の着替え用は、色違いのセットだと1枚あたりが安くなりやすい
- **洗濯への強さ**：毎日洗うので、縮みにくい素材か、ネットに入れて洗えるか

## 季節の変わり目は
秋冬ものは重ね着をするので、トップスは少しゆとりのあるサイズが使いやすいです。春になっても着られるよう、ひとつ上のサイズを選ぶ人もいます。
