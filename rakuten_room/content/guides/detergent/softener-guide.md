# 柔軟剤の選び方｜役割・香りの強さ・使う量と、詰め替えのまとめ買い
柔軟剤は、洗濯物をやわらかく仕上げたり、静電気をおさえたりするためのものです。役割と選び方のポイント、使う量の注意点をまとめました。

> 柔軟剤は使う量が多いほど効果が上がるわけではなく、入れすぎるとタオルの吸水性が下がることもあります。表示どおりの量を守りましょう。香りの強さは好みが分かれるので、周りの人への配慮も考えて、まずは小さいサイズで試してからまとめ買いするのが安心です。

## 柔軟剤の主な役割
- 衣類をふんわり、やわらかく仕上げる
- 静電気をおさえる
- 衣類に香りをつける
- しわを目立ちにくくする（商品による）

## 選ぶときのポイント
| ポイント | 確認したいこと |
|---|---|
| 香りの強さ | 強め・ほのか・無香料など。職場や学校で使う服は控えめが無難 |
| 香りの種類 | フローラル・せっけんなど。家族の好みに合わせる |
| 機能 | 部屋干し向け、静電気防止、しわ予防など |
| 容量と詰め替え | 詰め替え用・超特大サイズは容量あたりが安いことが多い |

## 使う量の注意点
- 洗濯物の量と水の量に合わせて、表示どおりの量を入れる
- 入れすぎると、すすぎ残しやタオルの吸水性の低下につながることがある
- 洗濯機の柔軟剤投入口に入れる。洗剤と混ぜて入れない

## 香りへの配慮
香りの感じ方には個人差があり、強い香りが苦手な人もいます。外で着る服は香りを控えめにする、量を守るなど、周りへの配慮も意識すると安心です。
