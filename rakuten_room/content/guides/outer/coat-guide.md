# コートの選び方｜素材・形・丈の違いと、重ね着を考えたサイズの選び方
通勤にも休日にも使える冬のコート。素材ごとの特徴と、形や丈の選び方、サイズ選びのポイントをまとめました。

> 暖かさを重視するならウール混の厚手のもの、軽さやお手入れのしやすさを重視するならポリエステルなどの化学繊維が扱いやすいです。中にジャケットや厚手のニットを着るなら、肩まわりと袖に余裕のあるサイズを選びましょう。

## 素材ごとの特徴
| 素材 | 特徴 |
|---|---|
| ウール（ウール混） | 空気を含んで暖かい。ウールの割合が高いほど上品な風合い |
| カシミヤ混 | やわらかく軽い。価格は高め |
| ポリエステル | 軽くてしわになりにくい。家で洗えるものも |
| 中綿入り | 軽くて暖かい。カジュアルな印象 |

## 形と丈の違い
- **チェスターコート**：襟付きで、スーツにもカジュアルにも合わせやすい
- **ステンカラーコート**：首元がすっきり。通勤の定番
- **ノーカラーコート**：襟がなく、やわらかい印象
- **ダッフルコート**：トグルボタンが特徴のカジュアルな形
- **丈**：ひざ上はすっきり、ひざ下は暖かく大人っぽい印象

## サイズ選びのポイント
商品ページの「肩幅」「身幅」「袖丈」を、手持ちのコートやジャケットの寸法と比べると失敗しにくくなります。中に着る服の厚みも考えて選びましょう。
