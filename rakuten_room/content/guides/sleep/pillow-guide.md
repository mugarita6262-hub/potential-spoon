# 枕の選び方｜高さ・素材・寝姿勢で合う枕を見つける基本
枕選びで一番大事なのは「高さ」です。寝姿勢に合った高さを決めてから、素材の好みで選ぶと失敗しにくくなります。

> 仰向けなら「首のすき間を埋めて、顔がやや下を向く高さ」、横向きなら「肩幅の分だけ高め」が目安。高さを調整できる枕を選ぶと、合わなかったときのリスクを減らせます。

## まずは寝姿勢を確認する
| 主な寝姿勢 | 合いやすい高さ | ポイント |
|---|---|---|
| 仰向け | 低め〜普通 | 首と敷き寝具のすき間を埋め、顔がわずかに下を向く角度 |
| 横向き | 高め | 肩幅の分だけ頭が下がらないよう、背骨がまっすぐになる高さ |
| うつ伏せ | 低め | 首を反らせないよう、薄めのもの |
| 寝返りが多い | 普通・幅広め | 横向きでも高さが足りるよう、両端が高めのもの |

仰向けと横向きの両方で寝る人は多いので、中央が低めで両端が高い形の枕も選択肢になります。

## 素材ごとの特徴
| 素材 | 感触 | 主な特徴 |
|---|---|---|
| 低反発ウレタン | ゆっくり沈む | 頭の形に沿ってフィット。熱がこもりやすいものも |
| 高反発ウレタン・ファイバー | 押し返す | 寝返りがしやすい。洗える商品もある |
| パイプ | 硬め・サラッと | 通気性が良く、中身の量で高さを調整しやすい |
| そばがら | 硬め | 通気性が良い。虫やにおいに注意して手入れが必要 |
| 羽根・羽毛 | 柔らかい | ふんわり包まれる。へたりやすいものもある |
| ポリエステルわた | 柔らかい | 価格が手頃で洗えるものが多い |

暑がりの人は通気性の良いパイプやファイバー、包まれる感触が好きな人は低反発や羽毛、というように選ぶと好みに合いやすいです。

## 失敗しないためのチェックポイント
- **高さを調整できるか**：中材の出し入れやシートの抜き差しで調整できると安心
- **洗えるか、カバーを外せるか**：毎日顔が触れるものなので、清潔に保ちやすいか
- **返品・交換の条件**：試し寝期間がある商品もある
- **サイズ**：寝返りが多い人は横幅に余裕があるもの

## 買い替えの目安
へたって高さが変わった、首や肩に違和感が出る、においが取れない、といったサインが出たら買い替えどきです。素材によって差はありますが、数年が一つの目安になります。
