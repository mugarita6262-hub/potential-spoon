# シーリングライトの選び方｜畳数に合う明るさ（ルーメン）の目安と、調光・調色の便利さ
部屋全体を照らすシーリングライトは、部屋の広さに合う明るさを選ぶのがいちばん大切です。明るさの目安と、あると便利な機能をまとめました。

> 照明の箱や商品ページには「〜6畳」「〜8畳」のように適用畳数が書かれています。これは日本照明工業会の基準に合わせた表示で、たとえば〜6畳用は2,700〜3,699ルーメン、〜8畳用は3,300〜4,299ルーメンが目安です。明るさや光の色をリモコンで変えられる「調光・調色」機能があると、時間帯や使い方に合わせられます。

## 畳数と明るさの目安
| 適用畳数 | 明るさの目安（ルーメン） |
|---|---|
| 〜6畳 | 2,700〜3,699 |
| 〜8畳 | 3,300〜4,299 |
| 〜10畳 | 3,900〜4,899 |
| 〜12畳 | 4,500〜5,499 |
| 〜14畳 | 5,100〜6,099 |

天井が高い部屋や、細かい作業をする部屋は、ひとつ上の畳数を選ぶと安心です。

## 光の色の違い
- **電球色**：オレンジがかった温かい光。くつろぐ部屋に
- **昼白色**：自然な白い光。リビングに
- **昼光色**：青みがかったはっきりした光。勉強や作業に

調色機能があれば、ひとつの照明でこれらを切り替えられます。

## 取り付け前に確認すること
シーリングライトは、天井の「引掛シーリング」という差し込み口に付けるものが多く、工事なしで取り付けられます。天井の差し込み口の形を確認してから選びましょう。
