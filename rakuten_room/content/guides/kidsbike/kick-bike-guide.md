# キックバイクの選び方｜何歳から乗れる？サイズの目安と、乗る場所の注意
ペダルのない子ども用の乗り物、キックバイク（ランニングバイク・バランスバイク）。対象年齢やサイズの選び方と、乗る場所の注意点をまとめました。

> キックバイクは、足で地面をけって進む、ペダルのない乗り物です。2歳ごろから乗れるものが多く、またがったときに両足の裏が地面にしっかりつく高さのものを選びます。キックバイクは道路で乗るための乗り物ではないので、公園など安全な場所で、大人が見守りながら乗りましょう。

## 選ぶときのポイント
| 項目 | 見方 |
|---|---|
| 対象年齢 | 2〜5歳ごろのものが多い。商品ごとの表示を確認 |
| サドルの高さ | またがって両足の裏がつく高さに調整できるか |
| 重さ | 軽いほど子どもが自分で持ち上げやすい |
| ハンドル | 高さを調整できると長く使える |
| ブレーキ | 付いているものと付いていないものがある |

## 乗る場所の注意
- 公道や車の通る道では乗らない
- 坂道は、スピードが出て止まれなくなることがある
- ヘルメットや、ひじ・ひざのプロテクターを付けると安心

## 自転車へのステップ
キックバイクでバランスをとることに慣れると、補助輪なしの自転車に移りやすいといわれています。自転車に移るときは[子ども用自転車の選び方](/kidsbike/kids-bike-guide/)をどうぞ。
