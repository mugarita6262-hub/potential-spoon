# スニーカーのお手入れ｜素材別の洗い方と、長持ちさせる保管のコツ
お気に入りのスニーカーをきれいに長くはくための、素材別のお手入れ方法と、普段からできるコツをまとめました。

> お手入れの基本は「汚れたらすぐ落とす」「はいたあとは湿気を逃がす」の2つです。洗い方は素材で変わるので、まず靴の内側のタグや商品の説明で素材と洗えるかどうかを確認しましょう。

## 素材別のお手入れ
| 素材 | お手入れの方法 |
|---|---|
| キャンバス（布） | 靴ひもを外し、ぬるま湯と中性洗剤でブラシ洗い。陰干しでしっかり乾かす |
| 合成皮革 | かたく絞った布で汚れを拭き取る。水に浸けて洗わない |
| 本革 | ブラシでほこりを落とし、専用のクリームでお手入れ |
| スエード | 専用のブラシで毛並みを整える。水洗いは避ける |
| メッシュ | やわらかいブラシで、こすりすぎないように |

## 長持ちさせるコツ
- 同じ靴を毎日はかず、1日休ませて中の湿気を逃がす
- はいたあとは、風通しのよい場所に置く
- 洗ったあとは直射日光を避けて陰干しする（色あせ・変形を防ぐ）
- 雨の日の前に、素材に合った防水スプレーを使う

## 白スニーカーをきれいに保つには
汚れは時間がたつほど落ちにくくなります。こまめにブラシや布で拭き、ソールのゴム部分は消しゴムタイプのクリーナーで落とせることもあります。
