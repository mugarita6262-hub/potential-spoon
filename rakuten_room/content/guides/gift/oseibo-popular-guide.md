# お歳暮で人気のジャンルと、相手別の選び方
お歳暮は、相手の家族構成や好みに合わせて選ぶと喜ばれます。よく選ばれるジャンルと、相手別の選び方、贈るときの注意点をまとめました。

> 迷ったら、家族みんなで楽しめるハム・ソーセージや洋菓子、お酒を飲む家庭ならビールなどの飲み物が定番です。一人暮らしや年配の方には量より質、小さな子どもがいる家庭には分けやすい個包装のお菓子が喜ばれます。生ものや冷凍品は、受け取りやすい日を考えて手配しましょう。

## よく選ばれるジャンル
| ジャンル | 特徴 |
|---|---|
| ハム・ソーセージ | 年末年始の食卓に。家族で楽しめる |
| ビール・お酒 | お酒を飲む家庭に。好みの銘柄が分かれば喜ばれる |
| 洋菓子・和菓子 | 日持ちするものが多く、贈りやすい |
| 調味料・油 | 実用的で、好みが分かれにくい |
| 海産物（カニ・魚介） | 特別感がある。冷凍・冷蔵の受け取りに注意 |
| カタログギフト | 相手の好みが分からないときに |

## 相手別の選び方
- **家族が多い家庭**：量が多いもの、個包装で分けやすいもの
- **一人暮らし・2人暮らし**：量より質。食べきれる量のもの
- **年配の方**：食べやすく、重くないもの。和菓子や上質な食品
- **小さな子どもがいる家庭**：子どもも食べられるお菓子やジュース

## 贈るときの注意点
- **冷蔵・冷凍の品**：相手が受け取れる日を考えて、配送日を指定する
- **アレルギーや好み**：分かっている場合は避ける
- **会社の取引先など**：会社の決まりで受け取れない場合もあるので、事前に確認すると安心
