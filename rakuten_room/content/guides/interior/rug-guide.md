# ラグの選び方｜サイズの目安・素材・お手入れのしやすさ
ラグは部屋の印象を大きく変えるインテリアですが、サイズや素材を間違えると「小さすぎた」「洗えなかった」となりがちです。買う前に決めておきたいポイントをまとめました。

> サイズはソファやテーブルとの位置関係で決めるのが基本。小さい子どもやペットがいる家庭は、洗えるタイプや汚れが目立ちにくい色を選ぶと手入れが楽です。床暖房やホットカーペットの上で使うなら、対応の表示を確認しましょう。

## サイズの目安
| サイズ（目安） | 畳数の目安 | 向いている使い方 |
|---|---|---|
| 130×185cm前後 | 約1.5畳 | ソファ前・一人暮らしのテーブル下 |
| 185×185cm前後 | 約2畳 | ソファ前に広めに敷く |
| 185×240cm前後 | 約3畳 | リビングの中心に。テーブルとソファを囲むように |

ソファの前に敷くなら、ソファの幅と同じくらいか少し広めにすると、まとまりよく見えます。部屋の中で敷きたい場所をメジャーで測り、マスキングテープで床に印をつけてみると、大きさのイメージがつかみやすくなります。

## 素材ごとの特徴
| 素材 | 特徴 |
|---|---|
| ポリエステル・アクリル | 価格が手頃で色や柄が豊富。洗えるものも多い |
| ウール | 弾力があり、へたりにくい。価格は高め |
| 綿 | 肌ざわりがさらっとしている。洗えるものも |
| い草・竹 | 夏向き。ひんやりした足ざわり |

## お手入れのしやすさ
- **洗えるかどうか**：「洗濯機で洗える」「手洗い可」などの表示を確認。大きいサイズは家庭の洗濯機に入らないこともある
- **毛足の長さ**：毛足が短いほうが、ゴミが絡みにくく掃除機をかけやすい
- **色・柄**：無地の淡い色は汚れが目立ちやすい。柄やミックスカラーは目立ちにくい

## 確認しておきたい表示
- **床暖房・ホットカーペット対応**：対応していないものを上に敷くと、変形などの原因になることがある
- **すべり止め**：フローリングで使うなら、裏にすべり止めがあるか
- **防音・厚み**：集合住宅で足音が気になるなら、厚みのあるものも選択肢
