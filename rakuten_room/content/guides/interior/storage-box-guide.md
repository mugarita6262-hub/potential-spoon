# 収納ボックスの選び方｜棚に合わせたサイズの測り方と素材の違い
収納ボックスは、入れる場所に合ったサイズを選ばないと「棚に入らない」「すき間が空く」といった失敗が起きがちです。測り方と、素材や形の選び方をまとめました。

> まず入れる場所の「内寸」（幅・奥行き・高さ）を測り、ボックスの「外寸」がそれより少し小さいものを選びます。同じシリーズでそろえると、見た目が整い、買い足しもしやすくなります。

## サイズの測り方
1. 入れる棚や押し入れの**内寸**（幅・奥行き・高さ）を測る
2. ボックスの**外寸**が、内寸より1〜2cmほど小さいものを選ぶ（出し入れのゆとり）
3. ふたつきや引き出し式は、ふたを開ける・引き出すための**手前のスペース**も考える

カラーボックスなど定番の棚には、その棚専用サイズのボックスが販売されていることが多いです。棚の商品名やサイズで検索すると見つけやすくなります。

## 素材ごとの特徴
| 素材 | 特徴 |
|---|---|
| プラスチック | 丈夫で水拭きできる。中身が見える半透明タイプも |
| 布（不織布など） | 軽くて、使わないときは折りたためるものが多い |
| ラタン・かご | 見せる収納に。湿気がこもりにくい |
| 紙・段ボール | 軽くて価格が手頃。重いものや湿気には弱い |

## 形・タイプで選ぶ
- **ふたつき**：ほこりを防ぎたいもの、季節ものの保管に
- **引き出し式**：衣類や日用品など、よく出し入れするものに
- **キャスターつき**：ベッド下やクローゼットの奥に。重いものでも出しやすい
- **積み重ね可能**：縦の空間を使える。耐荷重を確認する

## 買う前のチェック
- 何を入れるか（衣類・書類・おもちゃなど）を先に決めて、必要な個数を数える
- 中身が分かるように、ラベルを貼れるか確認する
- 同じシリーズで買い足せるか（廃番になりにくい定番品か）
