# 自転車の選び方｜種類・サイズ・電動アシスト、買ったあとに必要なこと
自転車は、使い方によって向いている種類が大きく変わります。主な種類の違いと、サイズの選び方、買ったあとに必要な手続きをまとめました。

> 近所の買い物や通学ならシティサイクル（ママチャリ）、スピード感のある通勤ならクロスバイク、坂道が多い・子どもを乗せるなら電動アシスト自転車が目安です。サイズはメーカーが示す「適応身長」で選びましょう。買ったら防犯登録をして、ヘルメットもあわせて用意すると安心です。

## 主な種類
| 種類 | 特徴 | 向いている使い方 |
|---|---|---|
| シティサイクル | カゴや泥よけつきで日常使いしやすい | 買い物・通学 |
| クロスバイク | 軽くて速く走れる | 通勤・運動 |
| 電動アシスト自転車 | こぐ力を電気で補助する | 坂道・長い距離・子ども乗せ |
| 折りたたみ自転車 | たたんで車や部屋に置ける | 置き場所が限られる |
| 子ども乗せ自転車 | 前や後ろに子どもを乗せられる | 保育園の送り迎え |

## サイズの選び方
自転車のサイズは、タイヤの大きさ（インチ）で表されることが多く、メーカーごとに「適応身長」が示されています。サドルを一番下げたときに、足が地面につくかどうかも確認しましょう。子ども用は成長が早いので、少しだけ余裕のあるサイズを選ぶ家庭が多いです。

## 子どもを乗せるなら
子どもを2人乗せる場合は、「幼児2人同乗基準」に適合した自転車を選びます。チャイルドシートの取り付けや、乗せられる子どもの年齢・体重の目安は、自転車とシートの説明書で確認しましょう。

## 買ったあとに必要なこと
- **防犯登録**：自転車を使うときは、防犯登録をすることが法律で義務づけられている。購入した店などで手続きできる
- **ヘルメット**：自転車に乗るすべての人に、ヘルメットの着用が努力義務になっている
- **点検**：ブレーキやタイヤの空気、ライトを定期的に確認する
- **保険**：多くの自治体で、自転車保険への加入が義務または努力義務になっている。住んでいる地域のルールを確認
