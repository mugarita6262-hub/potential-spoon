# ドライヤーの選び方｜風量・重さ・消費電力の見方と、家族で使うときのポイント
毎日使うドライヤーは、乾かす時間と持ちやすさで満足度が変わります。仕様表の見方と、選ぶときのポイントをまとめました。

> 乾かす時間を短くしたいなら、風量（〇㎥/分）の数字が大きいものを選びます。腕が疲れやすい人は本体の重さも確認しましょう。消費電力が大きいドライヤーは、ほかの家電と同時に使うとブレーカーが落ちることがあるので注意が必要です。

## 仕様表の見方
| 項目 | 見方 |
|---|---|
| 風量（㎥/分） | 数字が大きいほど一度にたくさんの風が出る。大風量タイプは乾くのが早い |
| 消費電力（W） | 1,200W前後が多い。同じコンセント・回路の家電との同時使用に注意 |
| 重さ（g） | 本体だけの重さか、コード込みかを確認 |
| 温風・冷風の切り替え | 仕上げの冷風があると、スタイルを整えやすい |

## 選ぶときのポイント
- **髪の量・長さ**：ロングや毛量が多い人は大風量タイプが向いている
- **折りたたみ**：収納や旅行に便利
- **ノズル**：風を集めるノズルや、毛先を整えるアタッチメント付きのものも
- **家族で使う**：温度や風量の切り替えが多いと、それぞれに合わせやすい

## 長く使うために
吸い込み口にほこりがたまると、風量が落ちたり熱くなりすぎたりします。説明書に従って、フィルターを定期的に掃除しましょう。コードを本体に強く巻き付けると断線の原因になります。
