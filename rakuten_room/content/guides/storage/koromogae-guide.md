# 衣替えの進め方｜しまう前の準備と、収納用品の選び方
季節の変わり目の衣替え。しまう前にやっておきたいことと、衣装ケースや収納袋の選び方をまとめました。

> しまう前に「洗う・乾かす・仕分ける」の3つを済ませるのが基本です。汚れが残ったまましまうと、黄ばみやにおいの原因になります。たたむ服は引き出し式の衣装ケースに、吊るす服はカバーをかけてクローゼットに、と分けると出し入れがラクになります。

## しまう前の準備
1. **洗う**：一度でも着た服は洗濯やクリーニングをしてから
2. **よく乾かす**：湿気が残っているとカビの原因に
3. **仕分ける**：来年も着る服・手放す服を分ける

クリーニングのビニールカバーは通気性がよくないため、長期間しまうときは外して、不織布のカバーにかけ替えると安心です。

## 収納用品の選び方
| 収納用品 | 向いているもの |
|---|---|
| 引き出し式の衣装ケース | ニット、Tシャツなどたたむ服。中身が見える半透明タイプが便利 |
| 不織布の収納袋 | 通気性が必要な布団やウール製品 |
| 衣類圧縮袋 | かさばるフリースや化繊のアウター |
| 洋服カバー | コートやスーツなど吊るして保管する服 |

## 収納のコツ
- 衣装ケースは押し入れやクローゼットの奥行きを測ってから選ぶ
- 詰め込みすぎない（目安は8割程度）
- 中身を書いたラベルを貼っておくと、次の衣替えが早い
